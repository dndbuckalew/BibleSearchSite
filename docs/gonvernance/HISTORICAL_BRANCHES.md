# Historical Branch Governance

Purpose

This document identifies branches intentionally retained for
historical, audit, and governance purposes.

Branches not listed here should generally be considered active
development branches or candidates for retirement.

---

main

Purpose:
Authoritative repository baseline.

Status:
Active.

---

release/v1-beta

Purpose:
Historical release milestone representing the BTA Version 1 Beta
release lineage.

Retention Reason:
Preserves release history, production stabilization milestones,
Context implementation milestones, donation implementation work,
and deployment evolution.

Status:
Historical reference branch.

No active development should occur on this branch.

---

archive/mongo-foundation-validation

Purpose:
Historical archive preserving MongoDB foundation validation work.

Retention Reason:
Documents evaluation, validation, and retirement of MongoDB prior
to adoption of PostgreSQL + pgvector architecture.

Status:
Historical reference branch.

No active development should occur on this branch.
